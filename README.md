# 東京・保育施設向け事業用物件スクリーニング

`index.html` を開くとローカルで確認できます。GitHub Pages では、このディレクトリ内のファイルを公開対象にします。

## 調査条件

- 対象駅：高田馬場、新宿、西新宿、大久保、新大久保、早稲田、池袋
- 店舗または事務所、60㎡以上、駅徒歩13分以内、3階以下
- 公開情報に記載のないエレベーター、第二出口等は「不明」と表示
- 保育施設への適性は一次評価であり、行政・建築・消防上の確認ではありません

## 更新方針

日本時間の毎日0時に検索を行い、募集終了、重複、条件変更を確認します。複数媒体で条件が異なる場合は差異を残し、重要項目を推測で補完しません。公開前に面積、階数、徒歩分数、用途、情報日付を検証します。
